# WhatsApp Business Automation Bot

A production-oriented WhatsApp chatbot built with Python and FastAPI,
designed to automate customer interactions through WhatsApp.

## Features

- WhatsApp webhook integration
- Automated customer responses
- AI-powered conversations
- Conversation persistence
- PostgreSQL database
- Environment-based configuration
- Docker support
- Automated tests
